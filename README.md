# 🏈 NFL Matchup Analytics

¿Ser más rápido o fuerte significa necesariamente tener un mejor rendimiento en la NFL? Este proyecto busca ir más allá de comparar quiénes son los jugadores más fuertes o rápidos, para investigar qué características físicas y de movimiento se relacionan con un mejor desempeño en el campo. Para ello, se analizan datos de jugadores, jugadas, movimientos y estadísticas de PFF, enfocándose en la capacidad de los jugadores defensivos para generar presión sobre el quarterback. La explosividad se mide como la velocidad máxima alcanzada durante el primer segundo después del snap y se estudia mediante un modelo de regresión logística que también considera el contexto de cada jugada. Los resultados muestran que una mayor explosividad está asociada con una mayor probabilidad de generar presión, mientras que el peso no presenta un efecto independiente significativo.
