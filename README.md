# Hackathon-UNAM

Repositorio del equipo para el Hackathon NFL Big Data Bowl, UNAM.

- [`hackathon-unam/`](hackathon-unam/): **NFL Matchup Analytics**, el proyecto del equipo. La descripción, el hallazgo principal y las instrucciones de instalación están en [hackathon-unam/README.md](hackathon-unam/README.md).
- [`plantilla-hackathon/`](plantilla-hackathon/): plantilla original del evento, sin modificar.

Los datasets no se versionan; las instrucciones para obtenerlos están en el README del proyecto.
