# 🏈 NFL Matchup Analytics

¿Ser más rápido o fuerte significa necesariamente tener un mejor rendimiento en la NFL? Este proyecto busca ir más allá de comparar quiénes son los jugadores más fuertes o rápidos, para investigar qué características físicas y de movimiento se relacionan con un mejor desempeño en el campo. Para ello, analiza datos de jugadores, jugadas, movimientos y estadísticas de PFF, enfocándose en la capacidad de los jugadores defensivos para generar presión sobre el quarterback. Mediante un modelo de regresión logística, se estudia la relación entre la explosividad inicial y la generación de presión, considerando también el contexto de cada jugada. **Uno de los principales hallazgos es que la tasa de presión fue de 17.9% entre los jugadores con mayor explosividad, frente a 7.5% en aquellos con menor explosividad, aproximadamente 2.4 veces más.**
